# Sources des données

| Donnée | Source | Statut |
|---|---|---|
| Lingala (111 lignes) | `lexique-lingala-francais.csv` fourni par l'éditeur de l'application | À faire relire par des locuteurs |
| Kikongo (≈ 40 mots) | Léon Dereau, *Lexique kikongo-français / français-kikongo*, texte numérisé (archive.org) | **Droits à vérifier avant publication** ; orthographe des années 1950, variantes N./S. |
| Définitions anglaises | Webster's Unabridged 1913 (CSV fourni) | Domaine public (à confirmer pour ce fichier) |
| Espagnol (≈ 240 mots) | 15 fichiers CSV français-espagnol fournis (`fr-es_*.csv`) | Origine non précisée : à confirmer ; relecture recommandée |
| Définitions swahili (101) | *kamusi* (words.csv, code MIT ; données extraites du site kamusi.appsmata.com) | **Droits sur les données à vérifier** ; premier sens seulement |
| Contrôle du swahili | *Plain Swahili Dataset* (phrases, MIT) : utilisé uniquement pour vérifier que les mots existent, non inclus dans l'application | — |
| Allemand (44 mots, dont 10 phrases) | 3 fichiers CSV français-allemand fournis (`fr-de_*.csv`) | Origine non précisée : à confirmer ; relecture recommandée |
| Anglais complété (59 mots) | *SpanishFlashCards 1-3000* (Liberation Philology), glossaire espagnol→anglais | Licence non indiquée dans le fichier : à confirmer ; 13 sens corrigés à la main |
| Lot de dictionnaires CSV Bomoko Solution (lingala, swahili, kikongo, tshiluba, espagnol, allemand) | 11 fichiers `dictionnaire_*.csv` fournis par l'éditeur (listes simples et dictionnaires « complets » avec prononciation et phrases d'exemple) | À faire relire par des locuteurs natifs ; fusion décrite dans `MERGE_REPORT_CSV_PACK.md` |
| Afrikaans, espéranto, russe, zoulou, kikongo (Kituba) | `base_multilingue_traduction.csv` fourni par l'éditeur | Statut du fichier : « traduction initiale — relecture recommandée » ; kikongo (Kituba) : « à valider par locuteur compétent » |
| Autres langues | Rédaction initiale | **À faire valider par des locuteurs natifs** |

Ouvrages reçus mais non utilisés : *Peace Corps — Lingala, livre du formateur* (dialogues et leçons, pas de lexique
structuré ; OCR sans accents) et l'article de la revue Flaly n°7 sur les verbes sériels en lingala (grammaire).
Voir `MERGE_REPORT.md` pour le détail de la fusion.

Non utilisé : *Les 1 000 mots indispensables en espagnol* (Éditions First, 2009) : ouvrage protégé par le droit d'auteur
(mention d'interdiction de reproduction), son contenu n'est donc pas repris dans l'application.
