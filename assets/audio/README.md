# Enregistrements natifs

Déposez ici un fichier par mot et par langue :  assets/audio/<langue>/<id>.mp3
Exemple : assets/audio/ln/bonjour.mp3  (le mot « Mbote » prononcé par un locuteur lingala)

Formats acceptés : mp3, m4a, ogg, wav. Aucun code à modifier : l'application détecte
les fichiers au démarrage et les joue à la place de la voix de synthèse.
La liste des mots à enregistrer se génère avec :  python3 tools/recording_list.py ln
